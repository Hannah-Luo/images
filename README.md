# AIteam image assets

Public image assets for the experiment, served via the [jsDelivr](https://www.jsdelivr.com/) CDN.

This repository intentionally contains **only images** — no experiment code and no
answer keys. The application code lives in a separate (private) repository.

CDN base (after tagging a release, e.g. `v1`):

```
https://cdn.jsdelivr.net/gh/<user>/<repo>@v1
```

Image URLs then resolve as `…@v1/images/<group>/<question>/<file>.jpg`.
